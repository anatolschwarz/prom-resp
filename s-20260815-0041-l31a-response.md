# Phase 2 #31 — L2 “Boing”

Implemented the seventh built-in Basic level, `boing-007` / “Boing”. It uses the approved opaque `corner_L2_v1.png` wardrobe/hatstand environment, the existing transparent marble/mattress/teacup/sparkle runtime assets, a fixed falling shelf, a high goal, one Spring mattress, and three data-defined placement targets.

The player mattress is an explicit `MattressDefinition` (rectangle geometry and spring restitution), independent of its Storybook sprite. A generic ball–mattress contact applies deterministic upward velocity from the incoming vertical impact velocity and the mattress restitution. The same declarative geometry/restitution semantics run in Phaser/Matter and the headless Matter runner; no level-id branch or sprite-derived collision geometry was added.

The optional `referenceSolutions` shape now accepts named `mattresses` as well as existing ramps. Validation rejects empty placement routes and duplicate Ramp or Mattress placement IDs, using generic placement wording. L2 encodes `main-mattress-bounce` with `l2-mattress` at `(385, 430)`, `180×42`, restitution `1.42`. Headless simulation solves deterministically at tick **256**; relevant contacts are the shelf (14, 17), mattress (231), then goal (256).

The scene supports Storybook mattress spawn/drag/snap/removal, capture/Rerun restoration, Reset restoration, and visual-only mattress/scene poke reactions. The palette and pure game state now represent the registered `mattress` inventory count. Existing levels retain empty mattress arrays through validation normalization.
